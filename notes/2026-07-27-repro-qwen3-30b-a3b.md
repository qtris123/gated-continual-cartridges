| Config | What it is | New code needed? | Compute | Effort |

> **`FlexQwen3MoeForCausalLM`** (§2) before Phase-1/Phase-2 will run. ICL alone can dodge this (§5, Option A).

Everything below is the **4B pipeline with `MODEL_NAME` swapped**; the science is identical, only the model changes.

## 2. PREREQUISITE — implement `FlexQwen3MoeForCausalLM`

Why: the cartridge is a set of **trainable KV vectors prepended inside every attention layer**, and the sparse/AM
gaters install **attention-capture hooks**. This lives in the custom Flex attention path
(`cartridges/models/qwen/modeling_qwen3.py`). MoE only changes the **FFN** (attention is unchanged), so the port is
mechanical but must be done carefully.

**Plan (smallest viable change):**
1. Copy `cartridges/models/qwen/modeling_qwen3.py` → `modeling_qwen3_moe.py`.
2. Replace the dense `Qwen3MLP` (L83) inside the decoder layer with the **Qwen3-MoE block**: a router/gate
   (`nn.Linear(hidden, num_experts)`) + `num_experts` expert MLPs + top-k routing + (Qwen3 uses a shared-expert-free
   sparse MoE). Lift the exact math from HF `transformers.models.qwen3_moe.modeling_qwen3_moe.Qwen3MoeSparseMoeBlock`
   so weight names match the checkpoint (`mlp.gate.weight`, `mlp.experts.{i}.{gate,up,down}_proj.weight`).
3. **Keep the attention module and the cartridge KV-injection UNCHANGED** — that's the whole point.
4. Read `Qwen/Qwen3-30B-A3B-Instruct-2507`'s `config.json`: wire `num_experts`, `num_experts_per_tok`,
   `moe_intermediate_size`, `norm_topk_prob`, `num_hidden_layers` (48), `num_key_value_heads`, `head_dim`,
   `decoder_sparse_step`/`mlp_only_layers` (Qwen3-MoE may keep some layers dense — replicate that).
5. Register it: add `FlexQwen3MoeForCausalLM` to `cartridges/models/__init__.py`.
6. **Sanity gate (do this before ANY training):**
   ```bash
   .venv/bin/python -c "
   import torch; from transformers import AutoTokenizer
   from cartridges.models import FlexQwen3MoeForCausalLM, HFModelConfig
   m = HFModelConfig(pretrained_model_name_or_path='Qwen/Qwen3-30B-A3B-Instruct-2507',
                     model_cls=FlexQwen3MoeForCausalLM).instantiate().to('cuda').to(torch.bfloat16)
   tok = AutoTokenizer.from_pretrained('Qwen/Qwen3-30B-A3B-Instruct-2507')
   ids = tok('The capital of France is', return_tensors='pt').input_ids.cuda()
   print('logits', m(ids).logits.shape)   # must run, finite, no missing/unexpected-key warnings
   "
   ```
   Verify: **zero missing/unexpected keys on load**, finite logits, and a short greedy generation reads sensibly.
   Cross-check a few next-token logits against stock `Qwen3MoeForCausalLM` on the same input (should match closely).

> If you only care about **ICL**, skip §2 and use §5 Option A (stock HF model, no cartridge).

record it.

## 5. Step A — ICL baseline (the acquisition/retention **ceiling**)

ICL = put the topic's papers in the prompt (no cartridge) and measure mean-CE loss on the answer tokens. **Two paths:**

**Option A — stock HF, no Flex port (recommended for ICL):** write/keep a tiny driver that loads
`AutoModelForCausalLM.from_pretrained('Qwen/Qwen3-30B-A3B-Instruct-2507')`, builds the full-context prompt, and
computes chunked loss on the answer span. Reuse the exact loss/chunking from
`examples/qasper2/experiments/qasper_loss_benchmark.py::evaluate_loss_chunked` (that's the function the 4B run used;
it's architecture-agnostic). This needs **no §2**.

**Option B — the shipped harness:** add a `ModelSpec` to `DEFAULT_MODELS` in `qasper_loss_benchmark.py`:
```python
ModelSpec(family="qwen30b", model_name="Qwen/Qwen3-30B-A3B-Instruct-2507",
          phase1_cartridge="", phase2_cartridge="")   # cartridges filled later (§6/§7)
```
…then (this path instantiates the **Flex** model → needs §2):
```bash
$PY examples/qasper2/experiments/qasper_loss_benchmark.py \
  --models qwen30b --only-methods icl_QA_raw icl_MT_raw \
  --qa-eval data/qasper/eval/qasper_eval_QA.parquet \
  --mt-eval data/qasper/eval/qasper_eval_MT.parquet --download-evals 2>&1 | tee logs/icl_30b.log
```
**Report** the two **diagonal** results only — `icl_QA_raw|QA` (QA ceiling) and `icl_MT_raw|MT` (MT ceiling) — as the
mean-CE `loss` (= ln ppl). The off-diagonals (wrong-topic context) are sanity checks, not the ceiling; skipping them
saves ~2 of the 4 long evals. Kill the PID after the loss line prints (foot-gun F2).

## 6. Step B — Phase-1 cartridge (dense self-distillation on QA) — *fresh for 30B*

The 4B study used a **human-provided** HF cartridge (`qtris123/qwen_qasper-QA-task_8192_512_no-cartridge_10-epochs`).
No such cartridge exists for 30B, so **train one** with `baseline_initial.py` (text-init → dense self-distillation):
```bash
NUM_GPUS=1 MODEL_NAME=Qwen/Qwen3-30B-A3B-Instruct-2507 NUM_TOKENS=512 \
TEXT_PATH=examples/qasper2/train/qwen_qasper_init_512.txt \
SYNTH_DATA_PATH=data/qasper/train/qwen_qasper_QA_task_8192.parquet \  # (§4: 30B-teacher synth if Option A)
EVAL_DATA_PATH=data/qasper/eval/qasper_eval_QA.parquet \
EPOCHS=10 LR=2e-2 GLOBAL_BATCH_SIZE=32 DISTRIBUTED_BACKEND=gloo \
RUN_NAME=phase1_selfdistill_qwen30b_512 \
bash examples/qasper2/scripts/train_baseline_initial.sh 2>&1 | tee logs/phase1_30b.log
```
Output: a `cache_last.pt` under `outputs/<launch-id>/<uuid>/`. **Stage it** (like the 4B one) at a stable path, e.g.
`outputs/phase1_selfdistill_qwen30b_512/cache_last.pt` (mind: `cache_last.pt` may be a per-rank symlink — foot-gun F5).
**Verify provenance** exactly like the 4B EXP-000-verify: eval on both splits — QA should be **≪** MT (QA-specialist,
MT-untrained). This QA number is your **retention floor** for the 30B.
> Confirm `baseline_initial.py`'s env names against its own header before launching (it prints them). It uses
> `KVFromText` from the init text and the same self-distillation objective as the cartridge.

## 7. Step C — Cartridge baseline (dense Phase-2 on MT)

Dense self-distillation continual update from the 30B Phase-1 cache (this is the **quality bar**):
```bash
CUDA_VISIBLE_DEVICES=0 \
PHASE1_CACHE_PATH=outputs/phase1_selfdistill_qwen30b_512/cache_last.pt \
SYNTH_DATA_PATH=data/qasper/train/qwen_qasper_MT_task_8192.parquet \
EVAL_DATA_PATH=data/qasper/eval/qasper_eval_QA.parquet \
MODEL_NAME=Qwen/Qwen3-30B-A3B-Instruct-2507 NUM_TOKENS=512 \
EPOCHS=10 LR=2e-2 GLOBAL_BATCH_SIZE=32 EVAL_EVERY_N_STEPS=15 SAVE_EVERY_N_STEPS=256 \
DISTRIBUTED_BACKEND=gloo WANDB_MODE=disabled RUN_NAME=refcart_phase2_qwen30b \
.venv/bin/torchrun --nproc_per_node=1 --master_port=29530 \
  examples/qasper2/train/baseline_continual.py 2>&1 | tee logs/refcart_30b.log
```
⚠ **LAST ≠ BEST (foot-gun F4):** on 4B the 10-epoch checkpoint **overfit** — the best cartridge point was **~4 epochs**
(QA 2.37 / MT 1.87 vs 10ep QA 2.70 / MT 2.21). So **save intermediate checkpoints** (SAVE_EVERY_N_STEPS is set) and
**eval several** (step ~256 ≈ 4 epochs, and the final) — report the Pareto-best, not just `cache_last.pt`. The run
prints "Done training waiting for final barrier" and may hang — the checkpoint is saved *before* the barrier; parse
the eval, confirm the `.pt`, kill the PID.

## 8. Step D — THE WINNER (sparse-gradient Phase-2 on MT)

A few sparse **gradient** steps, value-only, no-IDF attention-mass top-64 gate, from the 30B Phase-1 cache. **Run
`torchrun` DIRECTLY — do NOT use `train_continual_sparse.sh`, which force-defaults `BG_STATS_PATH` and silently flips
IDF back on (foot-gun F6).** Leaving `BG_STATS_PATH` unset ⇒ pure-TF (`use_idf=False`).
```bash
CUDA_VISIBLE_DEVICES=0 \
PHASE1_CACHE_PATH=outputs/phase1_selfdistill_qwen30b_512/cache_last.pt \
SYNTH_DATA_PATH=data/qasper/train/qwen_qasper_MT_task_8192.parquet \
EVAL_DATA_PATH=data/qasper/eval/qasper_eval_MT.parquet \
MODEL_NAME=Qwen/Qwen3-30B-A3B-Instruct-2507 NUM_TOKENS=512 \
EPOCHS=1 MAX_STEPS=62 GLOBAL_BATCH_SIZE=32 LR=2e-2 \
TOP_T=64 GRANULARITY=per_layer FREEZE_KEYS=1 MOMENTUM_MASKING=freeze \
EVAL_EVERY_N_STEPS=15 SAVE_EVERY_N_STEPS=256 \
DISTRIBUTED_BACKEND=gloo WANDB_MODE=disabled RUN_NAME=winner_sparsegrad_qwen30b_62 \
.venv/bin/torchrun --nproc_per_node=1 --master_port=29531 \
  examples/qasper2/train/continual_sparse.py 2>&1 | tee logs/winner_30b.log
```
Winner knobs (confirm names against `continual_sparse.py` L73–99): **`FREEZE_KEYS=1`** (value-only; default is 0 —
must set), **`GRANULARITY=per_layer`** (default is per_head — must set), **`TOP_T=64`**, **`MAX_STEPS=62`** (or **30** —
on 4B, 30 steps matched 62 at ~56% cost; acquisition plateaus by ~step 30), **`MOMENTUM_MASKING=freeze`**,
**no `BG_STATS_PATH`** (⇒ `use_idf=False`, the attention-mass gate). Confirm the log prints
`use_idf=False` and `Adam (lr=0.02)`. Produce both a 62-step and a 30-step checkpoint for the Pareto.

## 9. Eval (identical harness for cartridge / winner / Phase-1)

For every produced checkpoint, eval **both** splits with `eval_forgetting.py` and report the mean-CE **`Eval loss`**:
```bash
for SPLIT in QA MT; do
  CUDA_VISIBLE_DEVICES=0 CHECKPOINT_PATH=<run-dir>/cache-step<N>.pt \
  EVAL_DATA_PATH=data/qasper/eval/qasper_eval_${SPLIT}.parquet \
  MODEL_NAME=Qwen/Qwen3-30B-A3B-Instruct-2507 NUM_TOKENS=512 WANDB_DISABLED=1 \
  .venv/bin/python examples/qasper2/train/eval_forgetting.py 2>&1 | tee logs/eval_${SPLIT}.log
done   # parse `Eval loss - <float>`; KILL the PID after it prints (foot-gun F2)
```
- **QA = forgetting, MT = acquisition; lower is better.** Trust `Eval loss` (mean CE); **ignore the `perplexity`
  field** in these train logs (broken). ICL (§5) is the exception — its harness perplexity is self-consistent, but a
  **different harness**, so keep ICL as a *ballpark* ceiling, not strictly comparable to the eval_forgetting numbers.
- Eval sets are tiny (QA n=6, MT n=5 batches) → **treat sub-0.2 loss deltas as noise**.
