## 0. TL;DR — effort

**No model code to write.** Everything below is the 4B pipeline with `MODEL_NAME` changed. The only *work* is
training a fresh Phase-1 cartridge for 8B (the 4B study got its Phase-1 cartridge pre-made from HuggingFace; there is
no 8B one, so you train it — one dense self-distillation run).

| Config | What it is | Depends on | Compute |
|---|---|---|---|
| **ICL baseline** | full-context (papers in prompt), raw model, loss on answers | nothing | inference (77–103k-token context) |
| **Phase-1 cartridge** | dense self-distillation on QA (text-init → distill) | (optional) 8B-teacher synth | 1 training run (~10 epochs) |
| **Cartridge baseline** | dense Phase-2 continual update on MT | Phase-1 cartridge | 1 training run (~10 epochs; best ≈4ep) |
| **Winner** | sparse-gradient Phase-2 on MT (value-only, no-IDF top-64, ~30–62 Adam steps) | Phase-1 cartridge | ~minutes |

## 8. Step D — THE WINNER (sparse-gradient Phase-2 on MT)

A few sparse **gradient** steps, value-only, no-IDF attention-mass top-64 gate, from the 8B Phase-1 cache.
**Run `torchrun` DIRECTLY — do NOT use `train_continual_sparse.sh`, which force-defaults `BG_STATS_PATH` and silently
turns IDF back on (foot-gun F6).** Leaving `BG_STATS_PATH` unset ⇒ pure attention-mass gate (`use_idf=False`).
```bash
CUDA_VISIBLE_DEVICES=0 \
PHASE1_CACHE_PATH=outputs/phase1_selfdistill_qwen8b_512/cache_last.pt \
SYNTH_DATA_PATH=data/qasper/train/qwen_qasper_MT_task_8192.parquet \
EVAL_DATA_PATH=data/qasper/eval/qasper_eval_MT.parquet \
MODEL_NAME=$MODEL NUM_TOKENS=512 \
EPOCHS=1 MAX_STEPS=62 GLOBAL_BATCH_SIZE=32 LR=2e-2 \
TOP_T=64 GRANULARITY=per_layer FREEZE_KEYS=1 MOMENTUM_MASKING=freeze \
EVAL_EVERY_N_STEPS=15 SAVE_EVERY_N_STEPS=256 \
DISTRIBUTED_BACKEND=gloo WANDB_MODE=disabled RUN_NAME=winner_sparsegrad_qwen8b_62 \
.venv/bin/torchrun --nproc_per_node=1 --master_port=29531 \
  examples/qasper2/train/continual_sparse.py 2>&1 | tee logs/winner_8b.log
```
Winner knobs — **the ones you must set** (defaults differ; confirm names against `continual_sparse.py` L73–99):
- **`FREEZE_KEYS=1`** — value-only (default is 0 = keys train → wrecks retention).
- **`GRANULARITY=per_layer`** — default is `per_head`.
- **`TOP_T=64`**, **`MOMENTUM_MASKING=freeze`**, **`LR=2e-2`**.
- **`MAX_STEPS=62`** (1 epoch) — also run **`MAX_STEPS=30`** for the cheaper point (on 4B, 30 steps matched 62 at ~56%
  cost; acquisition plateaus by ~step 30).
- **no `BG_STATS_PATH`** ⇒ `use_idf=False`.

Confirm the log prints `use_idf=False` and `Adam (lr=0.02)`. Produce **both** a 62-step and a 30-step checkpoint.

## 9. Eval — identical harness for Phase-1 / cartridge / winner

For every checkpoint, eval **both** splits and report the mean-CE **`Eval loss`**:
```bash
for SPLIT in QA MT; do
  CUDA_VISIBLE_DEVICES=0 CHECKPOINT_PATH=<run-dir>/cache-step<N>.pt \
  EVAL_DATA_PATH=data/qasper/eval/qasper_eval_${SPLIT}.parquet \
  MODEL_NAME=$MODEL NUM_TOKENS=512 WANDB_DISABLED=1 \
  .venv/bin/python examples/qasper2/train/eval_forgetting.py 2>&1 | tee logs/eval_${SPLIT}.log
done   # parse `Eval loss - <float>`; then KILL the PID (foot-gun F2)
```
- **QA = forgetting, MT = acquisition; lower is better.** Trust `Eval loss` (mean CE); **ignore the `perplexity`
  field** in these training logs (broken). Eval sets are tiny (QA n=6, MT n=5 batches) → **sub-0.2 deltas are noise.**
